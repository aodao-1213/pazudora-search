    📖 使い方

    1. 素材・ダンジョンから検索する

    トップ画面の「素材・ダンジョン検索」から、探したいアイテム名やダンジョン名を入力して検索できます。

    • ① キーワードを入力
      「希石」や「たまドラ」、「億兆」などの一部の文字を入力し、「検索する」ボタンを押します（Enterキーでも検索できます）。過去の検索履歴からも選べます。
    • ② 検索結果の見方
      結果は「🏰 ダンジョン」と「💎 ドロップ素材」に分かれて表示されます。
    • ③ ダンジョンへのジャンプ
      表示されたダンジョン名（右端に ➤ が付いた行）をタップすると、そのダンジョンの報酬画面が開き、ハイライト表示されます。
    🔽 検索機能の使用例

    例として、ダンジョン「未知の新星/混沌の億兆龍」を「億兆」というワードで検索する。

    ① キーワードを入力

    検索ボックスに「億兆」と入力する。

    入力の際、検索履歴から楽に入力を済ませれます。

    入力を終えたら、検索ボタンを押す。Enter(改行)でも検索できます。

    ② 検索結果の見方

    「🏰 ダンジョン」には、「混沌の億兆龍」や「裏混沌の億兆龍」など3種類のダンジョンが表示されています。
    一方、「💎 ドロップ素材」には、「煌窮の億兆龍・アグリゲート」などの素材が表示されます。

    ③ ダンジョンへのジャンプ

    「未知の新星 / 混沌の億兆龍」の行をクリックすると、該当ダンジョンの報酬リストに飛ぶことができます。

    2. 報酬リストを活用する

    トップ画面の「報酬リスト」から、すべての闘技場シリーズのドロップ報酬を一覧で確認できます。

    • ① ステージ → ダンジョンの順に選ぶ
      報酬リストを開くと、ステージ（闘技場シリーズ）の一覧が表示されます。ステージを選ぶとダンジョンの一覧、ダンジョンを選ぶとそのダンジョンの報酬が表示されます。画面上部の「トップ › 報酬リスト › …」をタップすると、前の画面に戻れます。
    • ② アイコン（バッジ）の機能
      ドロップする素材のアイコンをタップ（または長押し）すると、その素材がどこで落ちるのかを「素材・ダンジョン検索」で即座に調べられます。
    • ③ アイコンに触れて詳細を確認
      パソコンではマウスを乗せると「素材名」がポップアップ表示されます。スマホではタップすると名前が確認できます。
    • ④ 素材の交換目安を見る
      ダンジョンの下部にある「🔄 素材の交換目安を見る」をタップすると、部位破壊素材などの詳しい交換レートを確認できます。

    ⚠️ 注意書き

    1. お願い

    この報酬一覧は、私自身でSNSや自分のスクショを基に作成しています。見落としも含めて、必ず正しいとは言えません。あくまでも目安として受け取っておいてください。

    2. 達成報酬(右上のタブ)について

    各ダンジョンを初クリアすると、MP50,000ptを獲得できる。また、1つの闘技場シリーズを初踏破するたびに魔法石25+1個を獲得できる(∞級1人専用コロシアムと極限降臨ラッシュを除く)

    3. ドロップの種類について

    • ①ボス・部位破壊
      ボスの本体や部位、乱入の部位のドロップです。特に数の記載がなければ、ドロップ数は各1つです(例外としては、新億兆など)。また、カッコ内にどれがどこでドロップするか記載してます。
    • ②確定ドロップ
      文字通り、確定でドロップするものです。
    • ③確率ドロップ
      文字通り、一定確率でドロップするものです。実際のドロップする確率はバラバラ。明らかに低確率のものはカッコで記載しています。
    • ④ランダムドロップ
      複数種類の中からランダムでドロップするものです。
      ランダムドロップの中でも確定でドロップするもの、不確定でドロップするものがあります。
      基本的には確定ランダムドロップですが、∞級1人専用コロシアムのみ確率ランダムドロップです。

    大樹の霊王を例とすると、

    ①ボス・部位破壊
    ボス本体では、『宿木の大樹霊王・アドネアの希石』、ボス部位では『宿木の大樹霊王・アドネアの左根の希石』と『宿木の大樹霊王・アドネアの右根の希石』、乱入部位では『神器に宿る者・グラオルの希石』をドロップする。

    ②確定ドロップ
    『潜在たまドラ☆枠解放』を "確定で" 1体ドロップする。

    ③確率ドロップ
    『ゴールドたまドラ』を "一定確率で" 1体ドロップする。

    ④ランダムドロップ
    『創装の宝玉』、『ダイヤドラゴンフルーツ』、『古代の三神面』の中からランダムで8個 "確定で" ドロップする

    ⚠ 部位のドロップについて注意

    • 当然ながら、部位は破壊しないとドロップしません。
    • 覚醒『部位破壊ボーナス』や、リーダースキルの『部位破壊素材ドロップボーナス』が不十分であれば、たとえ部位破壊したとしてもドロップしないことがあります。合計で100%を超えるようにしましょう。

      🛠 管理画面

      GitHub 接続

      保存ボタンを押すと、GitHub の設定ファイルを直接書き換えます。そのための「アクセストークン」を、このブラウザに1回だけ登録してください。

      状態：

      トークンを登録したブラウザでだけ、メンテナンス期間・お知らせの編集欄と、トップの「🛠 管理」ボタンが表示されます。

      トークンの作り方
      1. GitHub 右上のアイコン →「Settings」→ 左下の「Developer settings」を開く
      2. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
      3. Token name：わかりやすい名前（例：パズドラ管理画面）／ Expiration：有効期限（例：1年）
      4. Repository access：「Only select repositories」で pazudora-search だけを選ぶ
      5. Permissions →「Repository permissions」→「Contents」を Read and write にする
      6. 「Generate token」を押し、表示された github_pat_… をコピーして上の欄に貼り付け、「登録」を押す

      トークンはこのブラウザの中にだけ保存されます。別のパソコンやスマホで使う時は、そこでも登録してください。他人と共用のパソコンでは登録しないでください。漏れたかもしれない時は、GitHub の同じ画面からトークンを削除すれば無効になります。

      メンテナンス期間

      期間中は、一般の人にはメンテナンス画面が表示されます（?admin=… 付きで開けば、メンテ中でもサイトを確認できます）。
